1. アプリの概要
----------------------------------------------------------------

OPERATION LOG V2 は、フリーライセンス無線（DCR・LCR・特小・CB）の
交信記録をGoogleスプレッドシートと連携して管理するWebアプリです。

【特徴】
・ブラウザで動作するWebアプリ（インストール不要）
・データはブラウザ内に保存しつつ、Googleスプレッドシートにも
　自動送信してクラウド保存できる
・オフライン中でも記録可能（後でまとめて送信）
・PC・タブレット・スマートフォンで動作
・ダークモード・ライトモード切替に対応

【Lo版との違い】
・Googleスプレッドシートとの連携機能あり（要設定）
・CSVインポート機能あり
・PCでの使用を主に想定

【対応ブラウザ】
・Chrome推奨
・Safari・Firefox・Edgeでも動作

【アクセス方法】
https://jq3jqo-station.github.io/operation-log/operation_log_v2.html

2. 画面構成
----------------------------------------------------------------

画面は3つのタブで構成されています。

　［入力］　　　　　→ 交信ログを記録する
　［ログ一覧／検索］→ 記録したログを確認・検索・編集する
　［データ管理］　　→ データの保存・送信・バックアップ・削除を行う

ヘッダー右端の［☀ ライト］ボタンでダーク・ライトモードを切替できます。
設定はブラウザに記憶され、次回起動時も維持されます。

画面上部の自局QTHバーに現在の運用地が表示されます。


----------------------------------------------------------------
3. 初回起動時の設定
----------------------------------------------------------------

初回起動時に2つのウィンドウが順番に表示されます。

【① 自局の運用地を設定】
・都道府県（必須）：プルダウンから選択
・市区町村（任意）：テキスト入力
・詳細（任意）　　：山名・施設名など
設定後「設定する」をタップします。

【② クラウド保存先の設定（GAS URL）】
GoogleスプレッドシートのGAS URLを入力します。
クラウド保存を使わない場合は「スキップ」をタップします。

※ GAS URLの取得方法は別途「GAS設定ガイド」を参照してください。
※ 後から設定・変更する場合は「データ管理」タブから行えます。


----------------------------------------------------------------
4. 交信ログの記録（入力タブ）
----------------------------------------------------------------

【入力の流れ】

① トランシーバーを選択
   DCR / LCR / 特小 / CB のいずれかをタップ

   ・DCR選択時　→ 出力（5W / 1W）を選択
   ・特小選択時 → 交信方法（単信 / レピーター）を選択
               　 レピーター選択時はレピーター名を入力（任意）
   ・LCR選択時　→ 距離をキロメートルで入力（任意）

② コールサインを入力
   ・コールサイン欄に入力（例：きょうとXX999）
   ・ひらがな・カタカナ・ローマ字のいずれで入力しても使用可能
     ただし以下の自動変換が行われます：
     　全角英数字　→ 半角英数字に変換
     　半角カタカナ → 全角カタカナに変換
     　英字　　　　→ 大文字に統一
   ・過去に交信したコールサインは自動的に候補として表示されます
   ・候補を選択した場合、種別を選択済みであれば種別は変わりません
   ・「/」の右の欄にはポータブル番号を入力（不要な場合は空欄）

③ レポートを入力
   ・送信・受信のRSTをプリセットボタンまたは直接入力で設定
   ・CBLの場合は「CBL」ボタンをタップ

④ 相手局のQTHを入力
   ・都道府県：プルダウンから選択（よく使う都道府県は上部に表示）
   ・市区町村：テキスト入力（任意）
   ・詳細　　：テキスト入力（任意）

⑤ 交信日時を確認・修正
   ・現在時刻が自動セットされています
   ・過去ログを入力する場合は日時を修正してください
   ・日時ピッカーをタップして年月日・時刻を選択します

⑥ メモを入力（任意）
   ・自由記述欄です

⑦「記録する」ボタンをタップ
   ・画面上部に「✓ ○○○ を記録しました」と表示されます
   ・画面下部に「本日の記録：○局」としてカウントが表示されます
   ・入力欄がリセットされ、次の記録に備えます
   　（トランシーバー種別はリセットされません）
   ・GAS URLが設定済みの場合、自動的にスプレッドシートに送信されます

【未送信バッジについて】
オフライン中や送信失敗時は入力タブ下部に未送信件数が表示されます。
「クラウドに送信」ボタンで後からまとめて送信できます。


----------------------------------------------------------------
5. ログの確認・検索（ログ一覧／検索タブ）
----------------------------------------------------------------

【コールサイン検索】
・検索欄にコールサインを入力すると、一致するログを抽出します
・ひらがな・カタカナ・ローマ字のいずれで入力しても検索できます
・「クリア」ボタンで検索をリセットします

【日付＋トランシーバー検索】
・年月を選択すると、その月のログを表示します
・DCR・LCR・特小・CB のボタンで種別を絞り込みできます
・「クリア」ボタンで検索をリセットします

【本日のログ（デイリーサマリー）】
・当日の交信ログを種別ごとにまとめて表示します
・「コピー」ボタンでテキストをクリップボードにコピーできます
・SNSやブログへの投稿にそのまま使えます

【ログ一覧】
・全ログが新しい順に表示されます
・各ログ行の右端に「編集」ボタンがあります


----------------------------------------------------------------
6. ログの編集
----------------------------------------------------------------

ログ一覧の各行にある「編集」ボタンをタップすると
編集ウィンドウが開きます。

【編集できる項目】
・交信日時
・コールサイン・ポータブル番号
・送信RST・受信RST
・相手局QTH（都道府県・市区町村・詳細）
・メモ

【編集できない項目】
・トランシーバー種別（DCR・LCR・特小・CB）
　　→ 種別を変えたい場合はそのログを削除して再入力してください

「保存する」をタップすると：
・ブラウザ内のデータが更新されます
・GAS URLが設定済みの場合、スプレッドシートの該当行も上書き更新されます

「キャンセル」をタップすると変更は破棄されます。


----------------------------------------------------------------
7. データ管理（データ管理タブ）
----------------------------------------------------------------

【クラウド保存先（GAS URL設定）】
GoogleスプレッドシートのGAS URLを設定・変更できます。
設定済みの場合はURLが表示されます。
未設定の場合は「未設定（クラウド保存無効）」と表示されます。

【データを保存する】
・CSVで保存：全ログをCSVファイルとして書き出します
　　　　　　　ExcelやGoogleスプレッドシートで開くことができます
　　　　　　　ファイル名：oplog_YYYYMMDD.csv
・バックアップ作成：全ログをJSONファイルとして書き出します
　　　　　　　　　　機種変更時やデータ移行に使用します
　　　　　　　　　　ファイル名：oplog_backup_YYYYMMDD.json

【データを読み込む】
・CSVテンプレートをダウンロード：
　　入力フォーマットのCSVファイルをダウンロードします
　　1行目：ヘッダー（項目名）
　　2行目：注意書き（日時の形式など）
　　3行目：入力サンプル
　　※日時は「2025/03/25 10:30」の形式で入力してください
　　※No欄は空欄で構いません

・CSVから読み込む：
　　CSVファイルを読み込んでログに追加します
　　OK　　→ 既存データに追加
　　キャンセル → 既存データを上書き

・バックアップから復元：
　　JSONファイルを読み込んでログを復元します
　　OK　　→ 既存データに追加
　　キャンセル → 既存データを上書き

【未送信データ】
スプレッドシートへの送信が完了していないログの一覧です。
「まとめてクラウドに送信」ボタンで一括送信できます。
オフライン中に記録したデータはここに蓄積されます。

【全データを削除する】
・ブラウザ内の全ログデータを削除します
・2回の確認ダイアログがあります
・この操作は元に戻せません
・削除前に必ずバックアップを作成してください
・スプレッドシート側のデータは削除されません


----------------------------------------------------------------
8. Googleスプレッドシート連携について
----------------------------------------------------------------

【仕組み】
記録した交信ログは以下の順で保存されます：

1. ブラウザのlocalStorageに保存（即時）
2. GAS URLが設定済みの場合、スプレッドシートに送信（即時）
3. オフライン時は未送信として蓄積、後でまとめて送信

【スプレッドシートの列構成】
ID / No / 日時 / 種別 / DCR出力 / 特小交信方法 / 特小レピーター名 /
LCR距離(km) / コールサイン / ポータブル / 送信RST / 受信RST /
相手局_都道府県 / 相手局_市区町村 / 相手局_詳細 /
自局_都道府県 / 自局_市区町村 / 自局_詳細 / メモ

【ログ編集時の動作】
アプリでログを編集して保存すると：
・ブラウザ内のデータが更新される
・IDをキーにスプレッドシートの該当行を上書き更新する
　（新しい行は追加されない）

【注意事項】
・スプレッドシート側を直接編集した場合、アプリ側には反映されません
・アプリ側が正のデータとして扱ってください
・スプレッドシートのバックアップは定期的に取ることを推奨します


----------------------------------------------------------------
9. データの保存について
----------------------------------------------------------------

【保存場所】
データはブラウザの「localStorage」に保存されます。

【保存容量】
約10,000件以上の記録が可能です。

【データが消えるケース】
以下の操作を行うとデータが消える場合があります：

・ブラウザの「閲覧履歴・サイトデータを削除」
・ブラウザのアンインストール

【対策】
・定期的に「バックアップ作成」でJSONファイルを保存してください
・スプレッドシートにも送信済みであれば二重にデータが保護されます

【他のデバイスへの影響】
このアプリのデータが増えても、他のブラウザ操作や
他のアプリへの影響はありません。


----------------------------------------------------------------
10. ダーク・ライトモードについて
----------------------------------------------------------------

画面右上の「☀ ライト」または「☾ ダーク」ボタンで切替できます。

・ダークモード：室内や夜間に適しています
・ライトモード：屋外や明るい場所での視認性が向上します

設定はブラウザに記憶され、次回起動時も維持されます。

11. よくある質問
----------------------------------------------------------------

Q. アプリを閉じてもデータは残りますか？
A. はい。データはブラウザに保存されているため消えません。

Q. オフライン（電波のない場所）でも使えますか？
A. 記録・閲覧は可能です。スプレッドシートへの送信はオフライン中は
   できませんが、未送信データとして蓄積され、オンラインになったあと
   まとめて送信できます。

Q. 複数のPCやスマホでデータを共有できますか？
A. スプレッドシートを確認すれば全デバイスの記録を一元管理できます。
   ただしブラウザのlocalStorageは各端末に個別に保存されます。

Q. 過去のログを修正したい
A. ログ一覧の「編集」ボタンから修正できます。
   スプレッドシートも自動的に上書き更新されます。

Q. アプリが更新されたとき、データは消えますか？
A. 消えません。アプリとデータは別々に管理されています。

Q. コールサインはどの文字で入力すればいいですか？
A. ひらがな・カタカナ・ローマ字のいずれでも入力できます。
   以下の自動変換が行われます：
   　全角英数字　→ 半角英数字に変換
   　半角カタカナ → 全角カタカナに変換
   　英字　　　　→ 大文字に統一
   検索・候補表示機能ではどの文字種で入力しても正しく機能します。

Q. スプレッドシートに送信されない
A. 以下を確認してください：
   ・GAS URLが正しく設定されているか（データ管理タブで確認）
   ・インターネットに接続されているか
   ・未送信データがある場合は「まとめてクラウドに送信」を試してください
